## 발견해서 수정한 통합 문제

- Compact runtime과 SDK가 서로 다른 WASM `StateValue` 클래스를 사용하던 문제: onchain-runtime-v3 3.0.0 직접 의존성·override·중복 제거 및 회귀 검사.
- 브라우저의 WASM·process·Buffer·assert 의존성 보완.
- SDK가 witness 예외를 `ContractRuntimeError.cause`에 감싸는 경우를 처리하여 미발급 안내와 검증을 정확하게 분류.
- Vite 6.4.3으로 갱신해 기존 알려진 개발 서버 취약점 수정.

## 아직 검증하지 않은 범위

- 실제 지갑 확장의 사용자 승인→균형 조정→제출 전체 흐름.
- 서로 다른 물리 기기에서 학생·학교 지갑으로 진행하는 시연.
- Preprod 배포 및 테스트 잔액 준비.
- 실제 체인에 동시에 제출된 중복 거래의 충돌 처리. 현재 실거래 중복 검사는 순차 요청이며 동시 요청 검사는 기존 로컬 API에 한정된다.
- 공개 거래 메타데이터의 종합 프라이버시 감사, 운영용 학교 인증/명부, 키 복구, 프로그램 철회·종료.
