# 발표·영상 대본

목표 길이 3~5분. 공식 영상 길이 제한으로 확인된 값은 아니며 자체 리허설 목표다. 실제 체인 지연을 고려해 촬영한다.

| 장면 | 보여줄 화면 | 설명 |
| --- | --- | --- |
| 문제 | MatchProof 첫 화면 | “가입 조건을 확인하려고 원본 사본까지 반복 보관해야 할까요?” |
| 기관 | 모의 기관 자료 선택·발급 | “기관은 가상 자료를 확인하고 신청자 키에 묶인 자격을 발급합니다.” |
| 신청자 | 자격 가져오기 | “정확한 가상 소득 6,500만 원은 신청자의 자료입니다.” |
| 업체 | 새 심사 요청 | “업체는 5,000만 원 이상과 기준일 혼인 상태만 요청합니다.” |
| 동의 | 공개 범위·기한·체크박스 | “신청자가 수신자와 공개할 결과를 확인합니다.” |
| 증명 | 진행 표시 → 확정 거래 | “개발용 테스트 지갑으로 서명하고 Midnight 개발 체인 확정을 기다립니다.” |
| 독립 확인 | 지갑 없는 업체 조회 | “신청자의 자격 파일 없이 같은 승인 기록을 읽습니다. 정확한 소득액은 없습니다.” |
| 거절 사례 | 소득 미달 안내·업체 미완료 | “자료가 기준을 충족하지 않으면 성공 기록을 만들지 않습니다. 구체적인 실패 사유도 업체에 보내지 않습니다.” |
| 한계 | 짧은 설명 | “모의 발급기관·가상 자료입니다. 실제 문서 진위와 회원 로그인은 후속 과제입니다.” |

시작 전에 배포·역할 연결·자격 발급을 준비할 수 있다. 요청은 촬영 직전에 만들고 10분 안에 증명한다. 지연 장면을 편집하면 기다린 시간을 표기한다. 과거 승인이나 녹화 화면을 현재 신규 거래처럼 설명하지 않는다.

화면 표시: Local Devnet / Synthetic data / Test wallet (automatic signing). 원본 0건 문구는 트래픽 측정값이 아니라 설계 설명이다. 체인 승인·공개 원장 구조·파일 전달 경계를 함께 보여 준다.
