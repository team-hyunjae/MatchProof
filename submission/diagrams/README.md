## 온체인과 체인 밖 서비스

| 구성요소 | 위치 | 역할 |
| --- | --- | --- |
| Midnight 계약의 공개 상태 | 온체인 | 정책·자격 commitment·요청·승인 기록을 유지한다. Midnight가 제출된 증명을 검증하고 상태 변경을 확정한다. |
| 인덱서 | 체인 밖 | 체인 상태를 따라가며 앱이 공개 기록을 조회할 수 있게 제공한다. |
| 증명 서버 | 체인 밖 | 비공개 입력으로 ZK 증명을 생성한다. |
| 참여자 앱 | 체인 밖 | 파일 전달·보관·동의·거래 제출·결과 표시를 처리한다. |

공개 조회는 신청자의 자격 파일과 지갑 없이 가능하다. 현재 앱은 설정된 인덱서의 응답에 의존하며 브라우저 자체의 체인 헤더·포함 증명 검증은 구현하지 않았다. 데모 인덱서는 개발 네트워크용 서비스이고, ‘공개’가 인터넷 공개 호스팅을 의미하지는 않는다. [Midnight 공식 정의](https://docs.midnight.network/glossary), [구현과 운영 구성](../../infra/compose.yml).
