# MatchProof 참여자별 데이터 흐름

발표용 단계 그림이다. 실거래 캡처가 아니며, 구현을 설명하는 도식이다. PowerPoint에는 수정 가능한 도형·텍스트·연결선으로 들어 있고, 아래 PNG는 영상 편집용 1920×1080 출력본이다.

- 점선: 체인 밖의 전달. 공개 등록값을 복사하거나 비공개 파일·증명 입력을 전달한다. 모든 점선 데이터가 비공개라는 뜻은 아니다.
- 초록 실선: 체인에 상태를 기록하는 거래.
- 파랑 실선: 확정된 공개 상태의 조회·전달.
