소스·계약·테스트·실행 방법·공개 거래 증거를 포함한다. `.gitignore`는 의존성, 빌드 산출물, 컴파일러·증명 키, 실행 중 지갑 연결 파일, 로컬 배포 주소, 비공개 상태를 제외한다. `infra/standalone.env.example`은 공개 개발용 예시로 포함하며 외부 코드의 기존 라이선스와 출처를 보존한다.
