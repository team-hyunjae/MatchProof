## 한 줄 설명

결혼정보업체가 원본 소득·혼인 서류를 보관하지 않고, 신청자가 동의한 가입 조건의 충족 여부를 Midnight 영지식 증명으로 확인하는 DApp.

## 문제와 사용자

결혼정보업체의 가입 심사는 소득과 혼인 관련 확인을 요구할 수 있습니다. 원본 사본을 반복 제출·보관하면 업체의 정보 보관 부담과 신청자의 노출 범위가 커집니다. MatchProof는 모의 검증기관, 신청자, 결혼정보업체의 역할을 분리하고 업체가 필요한 조건의 결과를 조회하게 합니다.

## 구현과 Midnight 활용

기관은 가상 자료로 신청자 키에 결합한 자격 commitment를 등록합니다. 업체는 배포·신청자·기한에 결합된 심사 요청을 만듭니다. 신청자는 발급 목록의 멤버십, 자신의 키 소유, 소득·혼인·최신성 조건을 Compact 회로로 검증하는 증명을 제출합니다. 성공은 체인 확정 후 표시하며 별도 업체 화면은 공개 인덱서에서 승인 기록을 읽습니다.

비공개 자격에는 정확한 가상 소득액과 확인일 상태가 포함됩니다. 공개 정책과 승인 기록에는 조건 충족 사실과 요청 기한이 남습니다. 데모 기준은 2025년 소득 5,000만 원 이상, 확인 기준일에 혼인 중 아님, 7일 이내 최신성입니다.

## 실행·시연

README의 설치 및 컴파일 절차 후 개발 네트워크를 준비하고 `npm run demo`를 실행합니다. 공식 테스트 지갑 어댑터로 가상 개발 거래를 서명합니다. 기관 발급 → 신청자 파일 보관 → 업체 요청 → 신청자 동의·증명 → 별도 공개 조회 순서입니다. 클릭 가이드는 `docs/matchproof-judge-guide.md`에 있습니다.

## 현재 한계와 신뢰

공공기관 API와 실제 회원 로그인은 연동하지 않습니다. 기관은 자료 내용을 알고 있으며 자료 진위는 기관 신뢰에 의존합니다. 가상 접수번호는 실회원 계정이 아닙니다. 공개 시각·정책·성공 기록에 의한 연결 가능성이 있으며 완전 익명을 주장하지 않습니다. 테스트 지갑은 자동 서명하므로 실제 지갑 확장 승인창을 검증한 것으로 설명하지 않습니다. 증명 서버의 실제 위치는 실행 환경에 따라 다르며 실개인정보를 넣지 않습니다.

## 검증 근거

기존 계약·클라이언트·브라우저 검증 결과는 `docs/matchproof-verification.md`에 있습니다. 9월 26일 새 작업공간에서 새 계약의 발급·요청·증명 확정·독립 조회 및 소득 미달·재사용·타인 파일 거절을 CLI로 검증했습니다. 공개 거래 증거와 빈 환경의 설치·컴파일·38개 테스트·빌드 결과는 `submission/workspace-verification.md`에 있습니다. 자동 검사 통과를 실제 지갑 확장·독립 물리 기기 검증으로 대체하지 않습니다.
