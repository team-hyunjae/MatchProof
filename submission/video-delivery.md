## 편집 방식

- 전체 영상을 3분으로 단순 가속하려면 약 1.63배가 필요하므로 문장 선택과 대기 구간 편집을 함께 사용했다.
- 목소리는 음높이를 유지한 1.08배속이다. 합성 음성을 추가하거나 새로운 발언을 만들지 않았다.
- 긴 공개 식별값 읽기, 반복 설명과 일부 상세 검증 설명을 덜어냈다. 기존 4분 52초 영상과 13개 원본 녹음은 그대로 보관한다.
- 요청·증명 대기 구간은 각각 일부를 5배·4배로 줄이고 화면에 `대기 구간 단축 / Wait shortened`을 표시한다. 전체 영상이나 목소리에 적용한 배속이 아니다.
- 실제 증명 클릭부터 확정 안내까지 약 24.3초였다는 측정값을 음성과 화면에 유지했다. 편집 후 화면 길이를 실행 성능으로 제시하지 않는다.
- 기관 발급, 신청자 동의, 실제 개발 체인 확정, 업체 조회, 별도 브라우저 조회와 소득 미달 거절을 유지했다.
- 증명 서버의 비공개 입력 처리, 인덱서 응답 의존, 만료 후 기록 보존, 모의 기관의 신뢰 범위도 설명한다.
- 전체 디코딩, 화면·음성 길이 일치, 문장 연결과 영어 자막 41개, 주요 전환 장면을 검수했다.
