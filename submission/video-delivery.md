## 편집과 확인 범위

- 사용자 녹음 01–13을 모두 사용했다. 원본 파일은 전날 폴더의 `narration/`에 그대로 보존했다.
- 앞뒤 무음을 정리하고 저주파 잡음과 음량을 조정했다. 말하는 속도를 바꾸거나 합성 음성을 추가하지 않았다.
- 영어 자막을 별도 하단 영역에 넣어 앱 화면의 버튼과 거래 결과를 덮지 않는다.
- 설명이 길어진 장면은 화면 정지 구간을 늘렸다. 증명 진행 장면은 원래 속도를 유지했다.
- 발급은 촬영 전에 확정한 기록이다. 성공 요청 DEMO-003의 실제 확정과 별도 브라우저 조회, DEMO-002의 실제 제출 전 거절을 보여준다.
- 실패 후 업체 장면은 거절 시도 이후에 기록한 실제 새로고침 화면을 사용했다.
- 13개 녹음의 인식 결과를 대본과 대조하고 영어 문장별 시간을 확인했다. 자막 간 겹침 없음, 13개 챕터, 전체 영상·오디오 디코딩 성공, 주요 전환 화면을 확인했다.
- 최종 음량 측정: -16.74 LUFS, true peak -1.31 dBTP. 이는 측정값이며 별도 플랫폼 규격 인증을 의미하지 않는다.

## 남은 제출 단계

1. 완성 영상을 한 번 재생해 목소리와 표현을 최종 확인한다.
2. 공개 또는 일부 공개 영상 링크를 확보한다. 자막 삽입본에는 같은 영어 자막을 화면에 중복 표시하지 않도록 한다.
3. 로그아웃 상태에서 영상 재생을 확인하고 제출 설명의 영상 URL을 채운다.
4. 최종 제출 폼의 필수 항목을 확인하고 접수 확인 화면이나 번호를 보관한다.

업로드 주소가 생기기 전에는 로컬 경로를 외부 심사위원에게 영상 URL로 전달하지 않는다.
